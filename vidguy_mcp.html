VidGuy MCP FAQ

What is an MCP server?

+

MCP (Model Context Protocol) is an open standard that lets AI agents use outside tools. An MCP server is the bridge between the agent and those tools. The VidGuy MCP server gives your agent more than 100 tools to make videos, images and social posts.

What can my AI agent make with VidGuy?

+

UGC ads, talking head videos, faceless videos, 3D animated stories, slide carousels, TikTok photo carousels, memes, voiceovers and dubs. It can also edit your own footage, swap characters and post the result to your social accounts.

Which AI agents work with VidGuy MCP?

+

Any client that supports remote MCP servers. That includes Claude, ChatGPT, Claude Code, Codex, Cursor, Gemini CLI, Grok, OpenClaw and Hermes. Every one of them has a setup guide on this page.

How do I connect VidGuy to Claude?

+

In Claude, open Settings → Connectors and add a custom connector. Name it VidGuy, paste https://www.vidguy.ai/api/mcp and sign in with your VidGuy account. Then ask Claude to make a video.

Can ChatGPT make videos with VidGuy?

+

Yes. In ChatGPT, open Settings → Connectors, turn on developer mode if it asks, click Create and paste https://www.vidguy.ai/api/openai/mcp. Sign in with VidGuy, then pick it from the tools menu in any chat.

How much does VidGuy MCP cost?

+

The MCP server comes with every paid plan, starting with Starter at $49 a month. Each video or image uses credits from your plan, and your agent can check the cost before it starts.

Will my agent spend credits without asking?

+

Your agent can price a job before it runs it, and credits come back on their own if a job fails. Claude and most other clients also ask before they use a tool, unless you tell them to stop asking.

How long does a video take?

+

Most videos are ready in 2 to 5 minutes. Your agent gets a job ID right away and checks back, so you can keep chatting while it renders.

Can my agent post to TikTok and Instagram for me?

+

Yes. Connect your accounts in VidGuy once. Your agent can then post to TikTok, Instagram, YouTube, LinkedIn and Pinterest right away, at a set time or into your posting queue.

Should I use the MCP server, the CLI or the skill?

+

Use the MCP server in chat apps like Claude, ChatGPT and Cursor. Use the CLI or the skill in terminal agents like Claude Code, Codex, OpenClaw and Hermes. All three reach the same VidGuy tools.
