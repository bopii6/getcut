# 「宏观棱镜」模板拆解（2026-09-18）

素材：三条片子，同一套版式——
1. `8月经济数据全部出炉`（数据解读片，2m45s）
2. `好事情国家要建立健全`（政策概念片，2m30s）
3. `9月14号工信部央行`（发布会/数据混合片，4m04s）

## 一、固定件（全程钉死）

| 件 | 位置 | 说明 |
|---|---|---|
| 背景照片 | 全屏 | 与选题相关的照片/K线图，压到 ~85-90% 黑，隐约可见纹理，基本不动 |
| 频道标 | 左上 | 圆头像 + @宏观棱镜 |
| 选题标题 | 顶部居中 | **金色粗体一行**，全程不变（"8月经济数据解读"） |
| 口播波形件 | 中下 | 白圆头像 + 橙色波形条（持续跳动）+ @宏观棱镜 小字 |
| 口播字幕 | 底部 | 白色一行，逐句替换（=口播字幕，非设计元素） |

## 二、中段舞台 = 章节状态机

每个章节 10-25s，结构固定：

```
kicker   小号金字   01 / 消费   或   02 / TRANSMISSION
title    特粗大字   章节论点（"外需快，内需慢"）
sub      灰色小字   限定语（"今年前8个月 · 同比变化"）
body     1-3 个图形动作按口播逐拍弹出，先弹的留在原地（累积式）
         章节结尾常一条金色分隔线收束
```

章节之间干净退场 → 下一章 kicker+标题进场。

## 三、图形动作清单（从三条片子里枚举）

| 动作 | schema 草案 | 用在什么时候 |
|---|---|---|
| `list` 关键词列表 | {items:['出口跑得快',…]} 3-4 行逐条弹 | 开场论点、并列要点 |
| `bars` 发散条形图 | {items:[{name,value:+/-}]} 零轴居中、两端"←下降/增长→"、逐条弹、条恒金色 | 一组 ± 同比数据 |
| `line` 时间序列 | {title,unit,x[],y[]} 逐点画线+每点标值 | 趋势怎么走到今天 |
| `big` 大数字 | {number:'70 / 70',label,note?,deco?:'dots'} 超大金字 | 一个数字就是论据 |
| `cards` 卡链 | {items:[{text,gold?}],caption?} 细白框深底卡逐张弹，可连成 A→B→C，末张金句金底 | 推理链、递进结论 |
| `grid` 网格卡 | {items[],cols} 2x2/2x3 细框卡 | 并列概念枚举 |
| `vs` 对比双栏 | {left:{name,value},right:{…}} | 内外/前后/新旧对照 |
| `arrow` 时间箭头 | {from,to,note?} "现在投入 → 很多年以后" | 强调时滞 |
| `cta` 结尾 | {summary,question?,slogan} 总结+提问互动+口号 | 收尾章节 |

数据片（1、3）证据=图表/大数字；概念片（2）证据=链条/网格——同一套动作库，导演按内容类型挑。

## 四、叙事结构（导演层）

- 开场 hook：一句话论点 + 3 拍关键词（15-20s）
- 正文 N 章，每章 = 论点标题 → 证据（图/数）→ 结论卡
- 收尾：总结 + 提问互动（"评论区聊聊"）+ 频道口号（"看懂宏观防走丢"）
- 节奏：一句字幕 ≈ 一个动作元素弹出

## 五、与智谷三段式的关系

- 三段骨架**同构**（顶带钉死标题 / 底带字幕 / 中段舞台）——骨架复用
- 智谷底带只有字幕；这里多一个**波形口播件**（新小组件）
- 智谷中段是"素材全出血 ↔ 深色粒子底图形动作"交替；宏观棱镜是"暗照片底 + 图形动作为主角"，**不吃素材截图**
- 新增能力：**原生 SVG 图表**（bars/line）——现有 6 套模板的 stat/compare 都只是数字卡，没有画坐标轴的
- 落地映射：`templates.py` 注册 modes → 渲染端新 `MacroVideo.tsx`（或 zhigu 换肤扩展）→ 导演 LLM 按章输出 kicker/title/sub/逐拍动作
