# 复刻 Niwo「任意内容生成短视频」核心功能 — 技术方案

> 2026-09-15 基于 niwo.studio 视频工作台全流程实测 + 前端逆向整理。
> 实测链路：上传素材包 → 内容确认 → 渲染配置 → 8 阶段渲染流水线 → 成片。

---

## 一、实测到的 Niwo 真实架构（复刻的蓝本）

### 1. 输入协议（已完整复刻 → 我们已有产出能力）
- `content.json`：内容层（title / script / hook_headline / sources / pronunciations / notes）
- `manifest.json`：素材层（file / kind / summary / tags / source_url / script_anchor / clip 窗口）
- 关键设计：**内容与渲染参数彻底分离**。渲染参数（render.json）由用户在界面上选，不在包里。

### 2. 上传链路（实测逆向）
```
浏览器解压 zip（本地解析，zip 本身不上传）
→ POST /video-studio/projects                     # 建项目，返回 project_id
→ POST /projects/{id}/upload-urls {files:[{path,size_bytes}]}
                                                  # 返回每个文件的阿里云 OSS 预签名 PUT URL + content_type
→ PUT <presigned_url> (逐文件并发上传, 前端并发=8)
→ PUT /projects/{id}/bundle {content, manifest, cover_path}
                                                  # 提交内容 JSON，服务端校验解析，status=ready
```
存储路径约定：`NIWO/video/{user_id}/{yyyymmdd}/{project_id}/images|videos/...`（OSS）

### 3. 渲染配置（render_json 真实结构，从接口响应中获得）
```json
{
  "video_format": "portrait_editorial",        // portrait_editorial | portrait | landscape
  "theme": {"mode": "auto"},                    // auto | light | dark
  "tts": {"enabled": true, "voice_id": "...", "speed": 100, "builtin_lexicon": false},
  "bgm": {"enabled": true, "category_or_file": "oss://NIWO/system/bgm/upbeat/22-22.mp3", "volume": null},
  "sfx": {"mode": "hook", "volume_scale": null},   // off | hook | accent | full
  "brand_bar": {"enabled": false, "text": null, "font": null, "style": null},
  "disclaimer": {"enabled": true, "text": "..."},
  "assets": {"character_dir": null},            // IP 形象
  "model": "niwo:fast",                          // 对外型号；内部调用 openai/gpt-5.6-luna
  "output": {"path": "output/{task_id}.mp4"}
}
```

### 4. 渲染流水线（UI 暴露的 8 阶段 + 后端 status 字段实测）
| # | 阶段 | 后端 status | 做什么（推断+实测） | 实测耗时 |
|---|------|-------------|---------------------|----------|
| 1 | 素材准备 | preparing_assets | 拉 OSS 素材、解 manifest、校验 | ~30s |
| 2 | 分镜规划 | planning_shots | script → 句子/分镜；素材按 script_anchor+tags 分配到镜 | 快速 |
| 3 | TTS 配音 | tts | 逐字合成 + 字幕时间戳（pronunciations 覆盖读音） | ~1min |
| 4 | 画面设计 | designing_visuals | LLM(openai/gpt-5.6-luna) 出每镜版式/配色/关键词高亮 | ~30s |
| 5 | 画面校验 | checking_visuals | 视觉模型复查每镜画面与描述一致性（enable_visual_review） | ~1min |
| 6 | 预览帧 | generating_preview | 生成关键帧预览 | ~30s |
| 7 | 最终合成 | rendering_video | ffmpeg 合成：画布+标题带+字幕+来源+BGM/SFX 混音 | ~2min |
| 8 | 上传成片 | uploading → succeeded | 成片传 OSS，发 download_url | 数分钟 |

计费：按次预扣积分（本次 45 积分/88 秒成片），失败退回（credits_refunded）。

### 5. 版式系统（竖屏信息版 = portrait_editorial）
- 1080×1920 画布；顶部钩子标题带（1-3 行，`[[ ]]` 高亮色块，中英文宽度 1:0.56）
- 中部嵌 16:9 内容区（视频/图片满屏 cover 裁切；图片完整展示+模糊铺底）
- 底部：逐字字幕、资料来源小字、免责声明、可选 IP 形象
- 版面可换（卡片式=纸卡+方形内容区），明暗基调自动/浅/深

## 二、本地复刻方案（MVP → v1）

### 技术选型（全本地方案，零云依赖，Windows 可跑）
| 组件 | 选型 | 说明 |
|------|------|------|
| 语言 | Python 3.12 | 已有 ffmpeg 8.1 环境 |
| TTS | edge-tts（免费）→ 可换 Azure TTS/CosyVoice | 带 word boundary 事件 → 字幕时间戳 |
| 分镜规划 | 规则引擎（句读切分 + script_anchor 匹配 + tags 兜底均匀分配） | v1 可加 LLM |
| 画面设计 | 模板引擎（Jinja2 式参数化版式） | v1 可加 LLM 选配色/版式 |
| 合成 | ffmpeg filter_complex（zoompan/xfade/drawtext/subtitles+ASS） | 性能最好、免 GPU |
| 字幕 | ASS 字幕（逐句，可做关键词染色） | 复用 [[ ]] 高亮语法 |
| 校验 | 抽帧 + 可选 VLM | MVP 可跳过 |
| 服务化 | FastAPI + 任务队列（先进程内，后 celery/redis） | 对齐 Niwo 的异步任务模型 |

### 目录规划
```
E:\短视频生成\videogen\
├── pyproject.toml
├── videogen\
│   ├── schemas.py          # content/manifest/render 三协议（pydantic，对齐 niwo）
│   ├── validate.py         # 打包前校验（可借鉴 niwo 的 validate_bundle.py）
│   ├── planner.py          # 阶段2：分镜规划
│   ├── tts.py              # 阶段3：edge-tts + 词级时间戳 + 多音字表
│   ├── designer.py         # 阶段4：版式/配色决策（模板 + 可选 LLM）
│   ├── subtitle.py         # ASS 字幕生成（含钩子标题带高亮）
│   ├── compose.py          # 阶段7：ffmpeg 合成（竖屏信息版/竖屏/横屏三模板）
│   ├── pipeline.py         # 8 阶段状态机（同名 status 对齐 niwo）
│   └── cli.py              # videogen build <bundle_dir> -o out.mp4 --format portrait_editorial
└── tests/
```

### 里程碑
1. **M0 跑通竖屏信息版**（1-2 天）：固定一个 voice + 无 BGM，图片 Ken Burns + 视频裁切 + 逐句字幕 + 钩子标题带，出第一条本地成片。
2. **M1 补齐声音层**（1 天）：edge-tts 语速/音色选项、多音字注音表、BGM 混音（自动闪避）。
3. **M2 版式系统**（2 天）：三形态模板、明暗基调、来源/免责声明脚注、[[ ]] 高亮。
4. **M3 服务化**（2-3 天）：FastAPI 上传/任务/进度接口（照抄 niwo 的 API 形状），前端可后接。
5. **M4 智能化**（可选）：LLM 文案→分镜精修、VLM 画面校验、IP 形象层。

### 与 Niwo 的差异（诚实边界）
- Niwo 的「画面校验」「智能音效编排」「IP 形象」是重 AI 环节，MVP 用规则替代，效果打折。
- 合成质量取决于模板打磨（动画缓动、字幕样式、转场节奏），这部分是体力活也是护城河。
- 我们的素材采集端（Agent Skill 素材包）已经和 Niwo 同构，做完成片端即全链路自主。
