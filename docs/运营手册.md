# GetCut 运营手册（一页纸）

线上：https://getcut.cn ｜ 服务器：152.136.119.62 ｜ 目录：`/opt/getcut`

## 1. 卖之前：确认三件事

1. 打开 https://getcut.cn ，粘一段文案，能出片（30 秒片约 30~90 秒渲染）。
2. 顶栏点「登录」→ 注册 → 顶栏出现邮箱和「免费剩 3 条」。
3. 打开 https://getcut.cn/api/health ，返回 `{"ok":true,"plan":true,"tts":true,...}`。

任何一条不对，先看第 5 节日志。

## 2. 发卡密（599 买断）

```bash
# 登录服务器
ssh -i ~/.ssh/videogen_ecs root@152.136.119.62
cd /opt/getcut/api

# 生成 20 张，批次号写当月
node scripts/gen-cards.mjs --count 20 --batch 2026-11
```

输出形如 `GC-BBN2-726M-07V2-GFFB`，一行一张，直接发给客户。

- 客户在页面点「599 买断」→ 输入卡密 → 核销；核销后账号 `pro=true`，不再限条数
- 同一张码重复输入返回「已解锁」，不会重复扣
- 别人用过的码会返回「已经被用过了」
- 卡密库存文件：`/opt/getcut/api/data/cards.json`（**要备份**）

**收款方式**：先微信/支付宝转账，再人工发码。没有接在线支付是有意的——微信商户号要 2~6 周，599 低频人工发码完全撑得住。

## 3. 看数据

```bash
# 有多少客户、出过多少片
cat /opt/getcut/api/data/store.json | node -e "const s=JSON.parse(require('fs').readFileSync(0));console.log('用户',s.users.length,'作品',s.gens.length,'买断',s.users.filter(u=>u.pro).length)"

# 磁盘（成片存在 data/videos，一条 3~8MB）
du -sh /opt/getcut/api/data/videos
df -h /
```

## 4. 备份（每周一次，别省）

```bash
cd /opt/getcut/api
tar -czf /root/getcut-backup-$(date +%F).tar.gz data/store.json data/cards.json
# 拉到本地
scp -i ~/.ssh/videogen_ecs root@152.136.119.62:/root/getcut-backup-*.tar.gz .
```

`store.json` 丢了 = 客户账号和作品全丢。

## 5. 排障

| 现象 | 先看什么 |
|---|---|
| 出片转圈很久 | `journalctl -u getcut-api -n 50 --no-pager`，看是不是 TTS 卡住 |
| 页面提示"配音失败" | 服务器 `python3 -c "import edge_tts"`；微软接口偶尔抽风，重试即可 |
| 额度显示不对 | `/api/me` 看 used/remaining；买断用户 remaining 是 -1 表示不限 |
| 卡密核销报错 | 先看校验位（错字会直接报"卡密有错字"），再看 cards.json 里 used 字段 |
| 502/白屏 | `systemctl status caddy getcut-api` |

重启：`systemctl restart getcut-api`（不影响已生成的作品文件）。

## 6. 改版面/发新版

```bash
# 本地
cd app && npm run build
tar -czf web.tgz -C dist .
scp -i ~/.ssh/videogen_ecs web.tgz root@152.136.119.62:/tmp/gc-web.tgz
ssh -i ~/.ssh/videogen_ecs root@152.136.119.62 "rm -rf /opt/getcut/web/* && tar -xzf /tmp/gc-web.tgz -C /opt/getcut/web"
```

## 7. 明确没做的事（别对客户承诺）

- 在线支付（走人工发码）
- 声音克隆真接（只有接口位，接阿里云百炼 CosyVoice 才能用）
- 成片过期清理（目前不自动删，磁盘 40G，约 6000 条才满）
- 多人协作、团队席位、发票

## 8. 599 都包含什么（对外口径）

- 13 种竖版风格，1080×1920，30fps，H.264 + AAC
- 不限条数（当前不设上限）
- 作品存服务器，可下载、可删除；换设备登录同邮箱还能看到
- 剪映草稿导出：还原时间轴和字幕，视频轨是占位素材（这点要提前说清，别让客户以为能一键出成片工程）
