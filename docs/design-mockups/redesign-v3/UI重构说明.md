## 一、为什么推倒重来（老板命令的翻译）

现有「黑金大报版」（页底 #0D0B14 + 描金 #CBB88A + 双金线 + 金色光晕 + 点阵底纹）的问题，不是某一处不好看，而是**整个气质选错了**：

| 层面 | 真问题 |
|---|---|
| 信息架构 | 首页报头/投料台/对照条/最近成片/全部项目全部居中堆叠，一屏里 5 个"主角"互相抢；生成页大标题写两遍（h1 和阶段标题重复喊话）；确认页"看什么"（素材）和"选什么"（配置）混在一条时间轴里 |
| 认知负担 | 深底金字让"哪些能点、哪些只是文字"全靠发光猜；装饰（点阵、光晕、双线）和信号（按钮、进度、状态）用同一套金色语言，权重失真 |
| 流程顺畅度 | 生成页下半屏整块留白，用户盯着一根小进度条发呆；导出页成片和操作挤在一起，历史版本是边角料 |
| 视觉质感 | "贵"靠金色发光堆出来——发光越多处越显廉价；双金线、印章、描边渐变全是同一招的重复 |

**结论：换气质，不是换皮肤。**

## 二、新设计语言：「纸白编辑部」

一句话：**纸是白的，字是墨的，朱砂只点在最值钱的一下上；影片是黑的，坐在墨色舞台里。**

与旧版的关系：每一根轴都反向。深→浅、冷→暖、金→朱砂、发光→发丝线、圆胖→方正、密集→留白。肉眼第一眼即知是两个产品，但版面骨架（流程优先、拖 ZIP 进来、四步制作间）保持。

### 2.1 Tokens（全站唯一定义处：index.html `:root`）

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#F7F5F0` | 页面底（暖白纸，非纯白，不刺眼） |
| `--card` | `#FFFFFF` | 卡片/面板/输入框底 |
| `--sunken` | `#F0EEE6` | 凹陷区：标签页底、代码底、进度条槽 |
| `--stage` | `#16140F` | **媒体舞台**：所有视频封面/播放器/模板小样的黑底座 |
| `--ink` | `#1C1A15` | 主墨色（标题/正文/主按钮底） |
| `--ink-2` / `--ink-3` | `#5F5C52` / `#98948A` | 次级 / 弱化文字 |
| `--line` / `--line2` | `#E5E2D8` / `#CFCBBD` | 发丝线 / 加重线（输入框描边） |
| `--acc` | `#C8401A` | **朱砂**：唯一强调色 |
| `--acc-hi` / `--acc-soft` / `--acc-ink` | `#A83414` / `#F9ECE5` / `#FFF7F2` | 朱砂 hover / 软底 / 朱砂上的字 |
| `--ok` / `--err` | `#2E7D4F` / `#B3261E` | 成功 / 失败（仅限状态语义，不当装饰） |
| 圆角 | `--r-s:3px --r-m:6px --r-l:10px` | 方正，印刷感；胶囊只留给进度条 |
| 阴影 | `--sh-1`（卡片极轻）/ `--sh-2`（浮层） | 其余层级靠发丝线和留白，不靠投影 |
| 字体 | Display(自托管 woff2) / 系统黑体 / mono | Display 只给编号、金额、百分比；文件名时长等元数据一律等宽 |

朱砂使用纪律（全站只有这些地方允许出现）：
开始生成按钮、下载 MP4、开通高级版、兑换（**值钱的一下**）；工位当前项下划线与完成对勾（**你在哪**）；区块小方章与编号、¥599 金额、进度条填充与百分比（**数字与刻度**）。除此之外全是墨与纸。

### 2.2 组件规范

- **按钮**：主按钮=墨底纸字（hover 加深）；值钱动作=`.go` 朱砂底；次级=白卡+1px 描边（hover 描边变墨）；幽灵=文字钮。全部 3px 圆角，disabled 落到 sunken 灰。
- **按钮系统里的钱**：`#go`（确认内容并开始生成）由 id 选择器强制朱砂——底栏那一下是全产品最贵的一下。
- **输入**：白底 1px `--line2` 描边，focus 变朱砂 + 3px 软底光环。
- **选择 pills/chips**：选中=墨底纸字（不是朱砂——朱砂不给"选中"这种状态，留给动作）。
- **开关**：on=朱砂，off=线灰。
- **工位导航**（制作间顶部的 01→04）：Display 数字方块，当前=墨底纸字+朱砂下划线，完成=朱砂对勾，未到=描边灰。发丝连线。
- **进度条**：4px 细条，槽=sunken，填充=朱砂（完成变绿）；配 64–104px 的 Display 大百分比数字。
- **状态章**：2px 直角小方章（已成片=绿软底，待制作=描边）。
- **浮层**（弹窗/菜单/任务面板）：白卡、`--sh-2` 投影、发丝分隔；遮罩=墨 40%+轻模糊。
- **动效**：只保留有信息的动（海报悬停浮起、上传进度、进度条扫描）；删掉了整页 fade（无头渲染里会定格在半透明初态，也是一次"闪"的噪音）。`prefers-reduced-motion` 全关。

## 三、逐页改动

### 3.1 工作台首页（`#/`）
- 新增**报头**（mast）：左侧「▪ 工作台」小方章 + 大标题，右侧 mono 统计（38 个项目 / 19 条成片）。信息一眼分层。
- 投料台仍是主角：白卡 + 虚线墨框，hover/拖悬整框变朱砂；ZIP 徽从"金框描边"改为**墨块纸字**（黑白反转后更稳）。
- 前后对照从两摞卡片改为**三格对照条**（你拖进来的 → 全自动 → 你拿到的），发丝线分隔，高度减半。
- 最近成片 rail、项目网格、筛选 chips 保留，全部换纸卡+发丝线；项目卡封面坐墨色舞台，标题压在渐变里。

### 3.2 制作间（四步流程）
- **工位导航**替代原步骤条（见组件规范）。
- 生成页去掉了重复的大标题（原来 h1 和阶段标题各喊一遍），内容区自己就是页面：大标题 → 一句话状态 → **巨大百分比**（Display 104px）→ 4px 朱砂条 → 「第 n/8 步 · 环节名」+ 已用时。完成态：数字 100%、条变绿、成片落座墨色舞台，下载/历史按钮就在手边。
- **确认页改成两栏**（本次最重要的 IA 改动）：
  - 左栏「素材单」（sticky 小卡）：素材已读入绿章、包名、mono 元数据（33 图 · 14 视频 · 文案 577 字 · 预计成片 · 规格）、看一眼原包内容 / 换一个素材包。
  - 右栏「制作选择」：画面（模板只占一格，点开才铺开，选完自动收起回填——保留原有交互）、声音（分组 pills + 试听）、高级设置折叠（配乐/音效/水印/来源）。
  - "看什么"和"选什么"从此视觉分离。
- 底部固定操作栏保留（决策永远在右下角），纸白毛玻璃+发丝顶线，状态句改 mono 小字。
- 导入步、导出步同一语言：导出页=左墨色舞台竖屏成片，右「下载与交付」（朱砂下载按钮、剪映按钮、mono 历史版本列表）。

### 3.3 定价页（`#/pricing`）
- 编辑部宣言式：「买断制·不订阅·不涨价」小方章起手 → 「一次付费，**永久是你的。**」→ **¥599 巨型 Display 数字**（¥ 是朱砂）→ 发丝线权益清单（朱砂小方块做 bullet）→ 怎么开通 01/02/03（Display 大编号）→ 卡密兑换白卡。
- 删掉了旧的朱红「永久有效」旋转印章（描金时代的一点红，现在是噪音）；「已开通」态用绿色小章表达。

### 3.4 落地页（访客）
- 悬浮胶囊导航改为**通栏白底导航**（发丝底线）。
- 报头两栏：左「你负责好想法，GetCut 负责出片」52px 墨字+朱砂「出片」，右侧手机坐墨色舞台；入场节奏保留（标题先落座，手机跟上来）。
- 成品展示 / 怎么做 / 免费试做三个区块统一「01/02/03 Display 编号 + 标题 + 发丝线」的编辑部栏头；试做卡白底朱砂按钮。

### 3.5 账号 / 直投 / 弹窗
- 登录注册、Agent 直投 `/i/<码>`、账号设置、品牌套装、联系创始人、「我的」菜单、任务面板、技能安装引导——同一套纸白组件，逻辑零改动。
- 顶栏删掉了**死按钮** `#tasksBtn`（重构前顶栏已无此入口，但 DOM 里还留着，既渲染无效又与测试断言矛盾）；任务角标只长在「我的」上。项目摘要与 logo 之间用发丝竖线分隔。

### 3.6 品牌资产
- Logo **形状不动**（圆角方块+右下斜切+播放三角），颜色随系统：站内=墨色，favicon=朱砂底纸色三角；`theme-color` 同步纸白。

## 五、自验记录（全部实测）

1. **本地服务**：开放模式 8600 + 门槛模式 8601 双实例起服务，免登录验收。
2. **无头 Chrome 逐页截图**（1440×980）：首页/确认/导入/生成（运行态+完成态）/导出/定价/落地，改版前后各一套。
3. **像素核对**：7 页取样全部命中 `#F7F5F0` 纸白、墨字 `#1C1A15`、朱砂 `#C8401A`、墨舞台 `#16140F`——主题翻转载荷像素级确认，无深色残留。
4. **visual-judge 视觉验收子代理逐页过**：首轮 6/7 pass；唯一 fail（导入页整页被定格在入场动画半透明初态）修复（删除整页 fade）后复验通过——**7/7 pass**，关键色全部像素级复核。
5. **主链路真实点通**（真浏览器 1440×980）：首页 → 新建项目 → 注入合法素材包 zip（真实上传+挂载链路，坏包先给出了人话报错「zip 里没有 content.json」——错误路径顺带验过）→ 自动落确认页（素材单卡数据正确）→ 选音色/换模板（样片弹窗→就用这个→自动收起回填）→ 点朱砂 CTA → 真实渲染启动（第 2/8 步·AI 配音 7%）→ 渲染完成 → 导出页可取片。
6. **前端测试**：29/29（见第四节）。

## 六、遗留风险（如实说）

1. **窄屏（≤760px）未真机验收**：无头 Chrome 最小窗宽 ~500px 会出伪影（本仓库已知坑），本次断点布局按同一套规则写并做了 860/760/640/480 四档，但按老规矩窄屏最终验收要用真浏览器拖一次。
2. **登录页弹窗**（门槛模式下点「登录」）没有单独截图留档——访客在落地页 hash 路由下无法直达 auth 视图（boot 对访客强制落落地页）；组件与确认页/设置弹窗同一套，风险很低，但没独立过 visual-judge。
3. **Intake 直投页**（`/i/<码>`）没有真实码可拍（需 Agent 投喂产生，24h 一次性），仅代码走查 + 与登录卡同构。下次 Agent 投喂时值得顺手看一眼。
4. **主题已从深色翻成纸白**：这是本次授权明确允许推翻的旧决策（「流程页固定深色」），但若老板看后想保留"制作间深色"，所有颜色都收在 `:root` + `.vg-flow` 两个作用域里，做一版"制作间保留墨色舞台全屏"的变体成本约半天。
5. 历史遗留 3 个测试失败在重构后全部转绿，其中 2 个（模板点击行为断言）建议后续观察是否稳定——本轮两跑皆绿。
