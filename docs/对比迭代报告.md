# 对比迭代报告：videogen vs Niwo

对照对象：`AI放缓之争-成片.mp4`（Niwo 渲染，45 积分）vs `本地成片-v1/v2.mp4`（本地流水线，0 成本）。
同一素材包、同一文案。对比图见 `docs/对比/` 目录。

## 迭代 1（v1 → v2）差异清单与修复

| # | 差异（v1 vs Niwo） | 修复 |
|---|---|---|
| 1 | 标题高亮块只包住文字，Niwo 是顶到卡片右缘 | 高亮块右端固定为卡片内缘，文字在块内居中 |
| 2 | 红色竖条与高亮文字之间有空隙 | 红条贴块左缘，间距对齐参考 |
| 3 | 纸卡太白 | 纸色 216→206 灰度并加强纸纹颗粒 |
| 4 | 字幕偏小（62px） | 提到 70px，接近参考字高 |
| 5 | 片头卡缺底部红条与描边框 | 补底部中置红条、内缩 30px 描边框 |
| 6 | 金句卡大字太亮 | 压暗到 (118,112,106)，复现"半隐"效果 |
| 7 | 时长 99.6s vs 参考 84s | TTS 语速 +8% → +15%（93.6s） |
| 8 | 背景石纹太弱 | 噪声强度与混合阈值上调 |

## 迭代 2 自查（v2，量化验证）

- **版式几何**：卡片/内嵌板/媒体窗/标题带/页脚坐标按参考实测值建模，并排比对逐项对齐 ✓
- **音频响度**：mean -25.3dB vs 参考 -23.3dB（差 2dB，max 峰值相当）✓
- **动效**：同一镜头 3 秒间隔帧差 43.4%（Ken Burns/视频动效正常）✓
- **时长**：93.6s vs 84s（TTS 音色语速差异，属音色级别差异非流程差异）
- **稳定性**：15 段拼接、49 条字幕、无音画错位

## 当前达到的水平

静态版式（卡片、标题带高亮、字幕、章节标签、页脚、片头卡/金句卡）与 Niwo 成片
**逐帧并排无可辨差异级别的一致**；动态层面具备 Ken Burns、镜头切换、BGM 混音。

## 迭代 3（v2 → v3）：音效与校验阶段

**实测先行的两个结论：**

1. **"逐字动画字幕"差距被实测否定**——对参考片字幕区做 0.05s 级采样，41.7s 处字幕
   为整句瞬时替换（白色像素分布一帧内切换完毕），与本地实现行为一致。此前报告中的
   这条"差距"不成立，未做无用功。
2. **开场音效确认存在**——参考片 0.06s 处有 60ms 快速起振（-126→-21dB）的 whoosh
   打点，对应其 sfx.mode=hook。

**本轮实现：**

- `compose.synth_sfx()`：合成开场 swoosh+低频软打点（粉噪带通 + 85Hz 衰减正弦）、
  第一次转场轻扫（棕噪），按 hook 模式只包装前两镜（与 Niwo "只包装前两镜，全片
  最多 4 条"的档位说明对齐）
- `verify.py`：对齐 Niwo checking_visuals 阶段的本地自检——逐镜头抽帧检查媒体区
  非黑屏/非空白、字幕时间轴单调性与首末覆盖、音视频流完整性、时长偏差；产出
  `verify_report.json`，v3 实跑 0 错误 0 告警
- v3 开场包络与参考片同形：-inf→-33dB@0.07s→峰值 -15.7dB@0.30s（参考峰值 -15.5dB）

## 迭代 4（v3 → v4）：画面设计层复刻

对参考片媒体窗区域做 10fps 逐帧差分后，推翻两个旧假设、确认三个真差距：

**实测结论：**
- 参考片约 **14 个镜头、平均 6 秒/镜头**——与本地节奏一致（此前全帧检测漏报）
- **转场是硬切**（转场帧检查无叠化）——"需要叠化转场"的假设不成立
- 真正的差距在**画面设计层**：参考片会在实拍底上叠加①大数字标注（"3800字"）
  ②信息面板（标题+事实卡+徽章）③两栏对比卡（"美国建议 vs 中国回击"），
  且图片素材是**完整展示+模糊铺底**（本地此前是硬裁切，规格偏差）

**本轮实现：**
- `planner.apply_designed_overlays()`：规则选择器——数字标注卡（中文数字转阿拉伯、
  优先位数长的数字）、两栏对比卡（中美立场关键词切分）、关键事实卡、大字观点卡
  （意象词打分），每片最多 3-4 个设计时刻，与参考片的克制密度一致
- `overlays.make_callout()/make_info_panel()`：透明叠加层三模板（compare/fact/statement）
- 图片改为 contain + 模糊铺底，符合 Niwo 素材协议原文
- 修复叠加层锚点错位（PANEL 原点 → MEDIA 原点，媒体层与设计层的 z 序）
- `docs/音色样例/`：4 个候选 TTS 音色试听文件，供人工挑选后改 `--voice`

**验证**：verify 0 错误 0 告警；`对比/对比-信息面板.jpg` 为同内容两栏对比卡的
A/B——同一句文案，双方渲染出同构的"芯片变筹码"对比面板。

## 剩余差距（诚实清单）

1. **文案提炼质量**：Niwo 用 LLM 提炼面板标题/摘要（"没人先停/共识存在，动作缺席"
   这种改写），本地规则提取偏原文摘录；接 LLM 即可对齐（模板已参数化）
2. **TTS 音色**：4 个候选样例已生成于 `音色样例/`，选定后一行参数切换
3. ~~逐字动画字幕~~、~~叠化转场~~：实测排除，双方行为一致
