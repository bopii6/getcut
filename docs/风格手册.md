# 竖版风格手册（8 套）

> 2026-11-04 定稿。竖版 1080×1920 / 30fps。三段式：顶部标题 / 中部主视觉 / 底部字幕。
> 共同底线：安全框 x∈[64,1016]；字幕带 y∈[1440,1600]；右侧 950–1080 只放装饰；
> 字重只用两端（思源黑体 Heavy / Noto Sans SC Light），中间字重不出现；
> 每屏只允许一个高饱和色，且必须有职能（状态/印章/锚点/结论），不做装饰。

## 按信任来源选型

- 要权威：`newsroom`（最像电视）、`broadsheet`（最像档案）
- 要算得清：`ledger`、`terminal`
- 要像我这个人：`reel`、`marker`
- 要卖得贵：`cover`、`swiss`

## 当前实现状态

- ✅ `newsroom`、`ledger` 已实现（`app/src/lib/styles.ts`）
- ✅ 老的四套（poster / magazine / dashboard / news / night）保留为调色板式
- ⏳ 待实现：`marker`、`broadsheet`、`cover`、`terminal`、`reel`、`swiss`

## 落地约定

1. 新风格写在 `styles.ts`，签名 `(ctx, beat, t, index, total)`，自己画顶部/中部/字幕，不走通用卡片。
2. 在 `types.ts` 的 `ThemeName` 加 id，`theme.ts` 里补一份 PALETTES（挡类型检查），`render.ts` 的 BGM 映射补一行。
3. 每套至少验证三帧：开场（hook）、数据/清单、收尾（cta），确认字不压边、句不超框。
