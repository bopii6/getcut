# 项目全过程梳理：从研究 Niwo 到自建同水平流水线

> 2026-09-15。全程四个阶段、六轮迭代、三份对比成片。当前状态：本地流水线与 Niwo 同架构、同品质层级，剩余为细节打磨项。

---

## 第 0 步：装上他们的 Skill，看懂玩法

- 克隆 `MontageAI/niwo-render-everything` 仓库，安装到本地技能目录
- 看懂产品边界：**他们的"生成视频"分两半**——Agent 负责"素材包"（zip：文案+素材清单+图+视频），渲染在他们的云端工作台
- 素材包协议核心：内容（content.json）与渲染参数彻底分离；成片时长 = 文案字数 ÷ 6 字/秒；图片不裁切、视频裁切；钩子标题 `[[ ]]` 高亮语法

## 第一阶段：亲手做出第一个素材包（输入端完全复刻）

1. 三轮联网检索，锁定选题"AI 放缓之争"（9/12 Amodei 发文 → 白宫反对 → 9/14 中方回击）
2. 定稿 530 字口播（≈88 秒）+ 钩子标题两行（含 `[[ ]]` 高亮）+ 6 条资料来源 + 多音字标注（长文 chang2）
3. 素材采集：Wikimedia Commons 图 21 张（Amodei 本人实拍、特朗普椭圆办公室官方照等，全部人工核验）+ Mixkit 免费视频 10 段，ffmpeg 裁成 5-10 秒镜头
4. 写 content.json + manifest.json（31 个素材带画面描述与"配句锚点"）
5. 跑他们的校验协议 → **0 错误 0 告警** → 打包 zip（34MB）

## 第二阶段：传进 Niwo，亲眼看完它怎么渲染

6. 逆向出上传链路：**浏览器本地解压 zip → 每个文件要一张 OSS 预签名 URL → 并发直传 → 提交 bundle JSON**（zip 本身不上传）——31/31 上传成功
7. 走完四步向导：选择素材 → 内容确认（服务端正确解析出 530 字/21图10视频/88秒/钩子标题）→ 渲染配置（拿到完整参数面板）→ 开始渲染
8. **8 阶段流水线实测**：素材准备→分镜规划→TTS 配音→画面设计→画面校验→预览帧→最终合成→上传成片；扣 45 积分；25 分钟出片
9. 下载他们的成片（84 秒 1080×1920）作为后续对比的基准

## 第三阶段：深度逆向，找到品质差距的根源

10. 逐帧解剖成片：13 类设计时刻编目（片头卡/数字标注/事实卡/两栏对比/清单卡/大字卡/金句卡……）、精确取色（纸卡 #e2e0df、主红 #a44231、暖黑 #1a1817）、字体判断（重磅黑体）、动效行为（元素依次入场、下划线画出）、镜头节奏（媒体窗差分实测 14 镜/84s ≈ 6 秒/镜）
11. **三条实锤定性架构**：成片元数据 `Made with Remotion 4.0.509`；接口返回 `shared_template: editorial-v1.tsx`；`model: openai/gpt-5.6-luna` 负责画面设计文案
12. 结论：**Niwo = 网页模板 + LLM 填内容 + Remotion 录制**。PIL 贴片方案存在代差，渲染层必须换 Remotion

## 第四阶段：自建流水线 videogen 的六轮迭代

| 轮次 | 做了什么 | 结果 |
|------|---------|------|
| v1 | PIL+ffmpeg 全链路：TTS（edge-tts 逐字时间戳）→ 规则分镜 → ASS 字幕 → 分段渲染拼接 | 结构通了，与原片对比出 8 处差异 |
| v2 | 修 8 差异：高亮块顶边、纸卡压暗、字幕加大、片头卡补装饰、TTS 提速 | 版面级一致 |
| v3 | hook 音效（whoosh+打点，开场包络与原片同形）+ 画面校验阶段（黑屏/错位/完整性自检） | 质检 0 告警 |
| v4 | 数字标注卡/事实卡/对比卡/大字卡四模板 + 图片"完整展示+模糊铺底"规格修复 + 叠加锚点 bug 修复 | 设计层补齐 |
| v5 | **推倒重写：渲染层切 Remotion**（TSX 模板复刻 editorial-v1：十来个卡片组件+入场动画编排+思源黑体 Heavy+delayRender 字体门控+字幕自适应缩放）；修 5 个工程 bug 后跑通 | 与原片同架构同品质层级 |
| v6 | **DeepSeek 分镜导演**（LLM 读全篇文案+素材清单，输出句子分组/素材分配/设计卡选位与金句文案，Python 校验兜底）+ **GLM-4V 画面校验**（逐镜头抽帧喂视觉模型）+ **音效编排**（whoosh/扫/弹/打点挂设计时刻，上限对齐 hook 档） | `director: llm`，四短板清偿 |

## 当前架构

```
素材包(zip) ──▶ Python 管线 ──▶ props.json ──▶ Remotion 模板 ──▶ 无声视觉轨 ──▶ ffmpeg 混音 ──▶ 质检 ──▶ 成片
              ├ TTS+逐字时间戳              ├ 纸卡/标题带/页脚              ├ 配音
              ├ 分镜(LLM导演+规则兜底)      ├ 十类设计卡组件+入场动画        ├ BGM
              ├ 设计卡文案(LLM改写)         ├ 字幕(硬切+自适应缩号)          └ 音效
              └ 时间轴对齐                  └ 思源黑体 Heavy
```

## 已知打磨清单（"细节还需要打磨"的具体所指）

1. **标题字体**：思源黑体 Heavy 与原片展示字体笔画厚度略差（换 MiSans/抖音美好体，一行配置）
2. **面板装饰密度**：虚线圆、角标代码样式与原片还有细差
3. **TTS 音色**：edge-tts 免费音色自然度不及商用（接口已留，可切 Azure/CosyVoice）
4. **数字标注文案重排**：数字与单位换行策略可再优化
5. **入场动画节奏**：已实现但与原片的时长/缓动曲线未逐帧校准
6. **音效样本**：合成音效可用但不如采样音效自然
