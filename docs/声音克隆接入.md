# 声音克隆接入

> 现状：前端接口位已完成（`app/src/lib/voice.ts`），服务端一条都还没实现。本文件是「把声音克隆接上真服务」的施工单：3 个新接口 + 百炼 CosyVoice 的调用顺序 + 录音与合规口径 + 上线前 3 个验证。
> 没接服务之前也能上线：`listVoices()` 只返回 5 个预设，克隆相关操作会给可读错误。

## 0. 边界

- 前端只认 4 个函数：`listVoices / uploadCloneSample / deleteClone / synthesize`。换供应商（百炼、火山、MiniMax）只改服务端，UI 不动。
- 预设音色 = edge-tts 发音人 id，`/api/tts` 原样透传（现有行为）。
- 克隆音色 id 由**我们自己的服务端**签发（`cl_xxx`）；上游 `voice_id`、`target_model`、`DASHSCOPE_API_KEY` 一律不下发浏览器。
- 本次只新增两个文件，没动 `proxy.mjs`。实现路由时注意两点：`readBody()` 只会 `JSON.parse`，multipart 要走 §2.2 的 `Request` 方案；`cors()` 只放行了 `POST, OPTIONS`，同源部署（vite 代理 / Caddy 反代）不受影响，但哪天前端跨域直连代理，`DELETE` 的预检会被拦。

## 1. 前端契约（已实现，可直接 import）

```ts
import { listVoices, uploadCloneSample, deleteClone, synthesize } from './lib/voice';

const voices = await listVoices();                    // 预设 + 已克隆（服务没就绪时只有预设）
const { id } = await uploadCloneSample(blob, '张律师'); // 失败抛 VoiceError（带 status/code）
await deleteClone(id);                                // 幂等：404 视为已删除
const mp3 = await synthesize('这句话用克隆音色念', id);  // ArrayBuffer，走 /api/tts
```

失败降级（上线验收第 2 条要按这个写）：

```ts
import { DEFAULT_VOICE_ID, synthesize, VoiceError } from './lib/voice';

async function speak(text: string, voiceId: string) {
  try {
    return await synthesize(text, voiceId);
  } catch (err) {
    if (!(err instanceof VoiceError) || voiceId === DEFAULT_VOICE_ID) throw err;
    console.warn(err.message);                       // 例：配音失败（HTTP 501 VOICE_NOT_CONFIGURED）：…
    return synthesize(text, DEFAULT_VOICE_ID);        // 只降级一次，成片照出
  }
}
```

## 2. 服务端要新增的 3 个接口

统一约定：鉴权沿用 `/api/me` 的 `gc_did` cookie，数据按设备/账号隔离；错误体 `{ "error": "人话", "code": "SNAKE_CASE" }`，HTTP 状态码同时表达类别。

### 2.1 `GET /api/voice/clones` —— 列表

| 项 | 内容 |
|---|---|
| 入参 | 无（可选 `?cursor=`、`?limit=`，默认全量） |
| 出参 200 | `{ "items": [{ "id": "cl_7f3a91", "name": "张律师", "preview": "https://…/cl_7f3a91.mp3", "createdAt": 1762300000000 }] }` |
| 规则 | **只返回上游 `status=OK` 的音色**；审核中 / 未通过的不返回。`preview` 可空；不要返回 `voice_id`、`target_model` |

### 2.2 `POST /api/voice/clone` —— 上传样本并克隆

| 项 | 内容 |
|---|---|
| Content-Type | `multipart/form-data` |
| 入参 | `sample`：音频文件（wav/mp3/m4a，浏览器直录的 webm/opus 也行，服务端转码）；`name`：展示名，1–20 字 |
| 出参 201 | `{ "id": "cl_7f3a91", "status": "ok" }`（上游已 `OK`） |
| 出参 202 | `{ "id": "cl_7f3a91", "status": "deploying" }`（20 s 内没等到 `OK`，前端只取 `id`，列表稍后出现） |
| 服务端流程 | 校验 → ffmpeg 转 24 kHz 单声道 WAV 16-bit（去首尾静音、峰值归一化）→ 质检 → `create_voice` → 轮询 `query_voice` → 落库 `{ id, device, name, upstream_voice_id, target_model, sample_key, status }` |
| 注意 | 同一设备建议限 5 个克隆；上游账号上限 1000 个音色（声音复刻与声音设计共用） |

不想装 multipart 解析库时，Node 18+ 可以这样白嫖 undici：

```js
const r = new Request('http://local', {
  method: 'POST', headers: req.headers, body: Readable.toWeb(req), duplex: 'half',
});
const form = await r.formData();
const sample = form.get('sample'); // File
```

### 2.3 `DELETE /api/voice/clones/:id` —— 删除

| 项 | 内容 |
|---|---|
| 入参 | 路径参数 `id`（`cl_xxx`） |
| 出参 | `204`，无 body |
| 规则 | 必须**同时**删：上游音色（`delete_voice`）、样本文件、本地映射。幂等：不存在或不属于本设备 → `404`（前端把 404 当成功）。上游删除失败也先删本地并记补偿任务，仍回 `204`——样本不能等 |

### 2.4 `POST /api/tts` —— 复用已有接口，只加一层 `voice` 解析

入参 `{ "text": "…", "voice": "cl_7f3a91" }`。`voice` 命中克隆 → 查映射拿 `upstream_voice_id + target_model` → 调 CosyVoice 合成 → 把音频字节流回来；否则按原逻辑走 edge-tts 预设。

| 错误码 | HTTP | 场景 | 前端表现 |
|---|---|---|---|
| `BAD_REQUEST` | 400 | 缺 text / 缺 name / id 为空 | 直接提示，不重试 |
| `SAMPLE_TOO_LARGE` | 413 | 样本 > 10 MB | 提示重录 |
| `SAMPLE_UNUSABLE` | 422 | 有效朗读 < 5 s、静音 > 40%、削波、底噪过高、有人声重叠 | 提示重录（附具体原因） |
| `UNSUPPORTED_FORMAT` | 415 | 非 wav/mp3/m4a/webm | 提示换格式 |
| `CLONE_NOT_FOUND` | 404 | id 不存在 / 已删 / 不属于本设备 | 列表刷新，回预设 |
| `CLONE_NOT_READY` | 409 | 还在 `DEPLOYING` | 提示「还在生成，稍等」 |
| `QUOTA_EXCEEDED` | 429 | 设备克隆数或账号音色数到顶 | 提示先删旧的 |
| `RATE_LIMITED` | 429 | 上游限流 | 退避重试 1 次 |
| `VOICE_NOT_CONFIGURED` | 501 | 服务端没配 key、路由未实现 | **降级到 `DEFAULT_VOICE_ID`**，不弹红 |
| `UPSTREAM_ERROR` | 502 | 百炼 4xx/5xx、审核未通过（`UNDEPLOYED`） | 提示 + 降级 |
| `UPSTREAM_TIMEOUT` | 504 | 轮询/合成超时 | 降级 |

## 3. 以百炼 CosyVoice 为例：create_voice → 轮询 → 合成

### 3.1 需要的密钥与配置

| 变量 | 必填 | 说明 |
|---|---|---|
| `DASHSCOPE_API_KEY` | 是 | 百炼 API Key，`Authorization: Bearer <key>`；和现有 `DEEPSEEK_API_KEY` 一样只放服务端 |
| `BAILIAN_WORKSPACE_ID` | 是 | 业务空间 ID，用于专属域名（推荐新域名，`dashscope.aliyuncs.com` 是旧域名） |
| `BAILIAN_REGION` | 否 | `cn-beijing`（默认）/ `ap-southeast-1` |
| `COSYVOICE_MODEL` | 否 | `cosyvoice-v3.5-flash`（默认，性价比）/ `cosyvoice-v3.5-plus`（重点客户） |
| `COSYVOICE_PREFIX` | 否 | 音色名前缀，**仅数字 + 字母、≤10 字符**，如 `gc` |
| `OSS_*`（或用 Base64） | 否 | 有公网 URL 最省事；MVP 可用 Base64 Data URI（20 s 24 kHz 单声道 WAV ≈ 1 MB，base64 后 ≈ 1.3 MB） |

> 域名：`https://{BAILIAN_WORKSPACE_ID}.cn-beijing.maas.aliyuncs.com/api/v1`。新域名迁移见百炼「地域与接入域名」。
> 变量读取沿用 `lib/env.mjs` 的 `envOf()`；记得把 `DASHSCOPE_API_KEY`、`BAILIAN_WORKSPACE_ID` 加进 `proxy.mjs` 顶部的 `applyEnv([...])` 列表，否则本机 `.env` 里的值不会生效。
> 音色与模型绑定：用 `cosyvoice-v3.5-flash` 创建的音色**不能**用 `cosyvoice-v3.5-plus` 合成，所以 `target_model` 必须跟音色一起落库。

### 3.2 调用顺序

```text
① create_voice（上传样本）→ output.voice_id
        ↓  通常几秒，审核慢时 30 s 内
② query_voice 轮询 → status: DEPLOYING → OK / UNDEPLOYED
        ↓  只有 OK 才可用
③ SpeechSynthesizer 合成 → output.audio.url → 下载字节 → 回浏览器
        ↓
④ delete_voice（用户删除时）
```

**① 创建音色**

```bash
curl -X POST "https://$WORKSPACE.cn-beijing.maas.aliyuncs.com/api/v1/services/audio/tts/customization" \
  -H "Authorization: Bearer $DASHSCOPE_API_KEY" -H "Content-Type: application/json" \
  -d '{
    "model": "voice-enrollment",
    "input": {
      "action": "create_voice",
      "target_model": "cosyvoice-v3.5-flash",
      "prefix": "gc",
      "audio": "data:audio/wav;base64,<样本>",
      "language_hints": ["zh"]
    }
  }'
# → {"output":{"voice_id":"cosyvoice-v3.5-flash-gc-xxxxxx"},"usage":{"count":1},"request_id":"..."}
```

可选参数：`enable_preprocess`（有底噪再开）、`enable_volume_normalization`、`max_prompt_audio_length`（3–30 s，默认 10）。

**② 轮询**（同一 URL，换 `action`）

```json
{ "model": "voice-enrollment", "input": { "action": "query_voice", "voice_id": "cosyvoice-v3.5-flash-gc-xxxxxx" } }
```

| `status` | 含义 | 我们的处理 |
|---|---|---|
| `DEPLOYING` | 审核/处理中 | 1 s 一次、最多 20–30 次；超时回 202 或 504 |
| `OK` | 可用 | 落库、返回 201、进列表 |
| `UNDEPLOYED` | 审核未通过 | 删样本，回 `422 SAMPLE_UNUSABLE`（别让用户反复试） |

**③ 合成**

```bash
curl -X POST "https://$WORKSPACE.cn-beijing.maas.aliyuncs.com/api/v1/services/audio/tts/SpeechSynthesizer" \
  -H "Authorization: Bearer $DASHSCOPE_API_KEY" -H "Content-Type: application/json" \
  -d '{
    "model": "cosyvoice-v3.5-flash",
    "input": {"text": "…", "voice": "cosyvoice-v3.5-flash-gc-xxxxxx", "format": "mp3", "sample_rate": 24000}
  }'
# → {"output":{"audio":{"url":"https://…"}}} → 再 GET 这个 url 拿字节
```

- `model` 必须等于创建时的 `target_model`。
- `format` 用 `mp3` 或 `wav` 都行，`audio.ts` 走 WebAudio 解码，两种都吃；`sample_rate` 24 kHz 足够口播。
- 返回的是**临时 URL**，要服务端二次下载；别把 URL 直给浏览器（会过期、会绕过鉴权）。
- 长句吞字：按 ≤25 字分句，复用现有 `/api/tts/batch` 的并发闸门（4 路）。
- 计费：创建音色免费，按合成字符计费；量级见 `docs/短视频声音设计包.md` §3.8。

## 4. 录音规范（客户侧 10–30 秒）

| 项 | 要求 |
|---|---|
| 时长 | **推荐 10–20 s**，有效朗读 ≥5 s，最长 ≤60 s；小程序/网页录制的硬上限设 30 s |
| 格式 | 上传 wav / mp3 / m4a；浏览器 `MediaRecorder` 出 webm(opus) 也可以，服务端 ffmpeg 统一转 **WAV 16-bit、24 kHz、单声道** |
| 采样率 / 声道 | 源 ≥16 kHz；服务端统一 24 kHz 单声道（双声道只取首声道） |
| 音量 | 语音 RMS **−18 dBFS ±2**；峰值 ≤ **−3 dBFS**（真峰值 ≤ −1 dBTP）；底噪 ≤ **−50 dBFS**；削波样本数 0 |
| 静音检测 | 20 ms 帧、**−42 dBFS** 门限、连续 3 帧判静音；首尾各留 0.3 s；句中停顿 ≤1 s（上游允许 ≤2 s）；静音占比 >40% 判不合格 |
| 内容 | 3–5 句完整朗读，正常语速，不唱歌、不耳语、不夸张情绪；单人、无 BGM、无他人声、无混响 |
| 环境 | ≤10 m² 小房间，关空调/风扇，距麦 10 cm，侧向 15° 防喷麦；同一段落在同一环境录完 |
| 质检 | 服务端收到先跑：时长、静音占比、削波、底噪、双人声；不合格直接 422 让重录，不要硬克隆 |

前端录制建议：`MediaRecorder` 用 `audio/webm;codecs=opus`（Safari 走 `audio/mp4`），先测 3 s 静音底噪给用户看波形，录完本地试听 + 显示时长，超 30 s 自动截断。

## 5. 合规（不做完别上线）

| 事项 | 要求 | 落点 |
|---|---|---|
| 授权 | 书面/电子授权书：姓名、用途、投放渠道、期限、删除权、是否允许二次修改；未成年人需监护人签；公众人物、他人声音、未授权员工一律拒绝 | 上传前勾选 + 授权书归档，与 `cl_id` 绑定 |
| 敏感信息 | 声纹属敏感个人信息：单独同意，告知处理目的/方式/范围/期限，可撤回（《个人信息保护法》） | 隐私政策 + 独立勾选框 |
| 删除 | 删除接口同时清样本、上游音色、映射与预览；承诺 ≤7 天物理删除，备份轮转同步 | `DELETE` 接口 + 补偿任务 + 后台可查 |
| AI 标识 | 显式标识（画面角标或口播「AI 配音」）+ 隐式标识（元数据）；发布时按平台勾选 AI 生成声明 | 导出页固定提示；依据《互联网信息服务深度合成管理规定》《人工智能生成合成内容标识办法》（2025-09-01 施行） |
| 存储 | 样本进私有桶、预签名短时 URL、最小权限；访问与删除日志留存 ≥6 个月 | 对象存储 + 审计日志 |
| 跨境 | 百炼国内地域数据不出境；换海外供应商（Azure 等）先做合规评估 | 合同/隐私政策 |

## 6. 上线前必须做的 3 个验证

**① 克隆相似度试听（不达标不许放量）**

- 同一段脚本 3 句：含金额/数字一句、>30 字长句一句、情绪句一句；克隆音色 vs 原声做盲听 A/B。
- ≥3 人（含客户本人）1–5 分打分，均分 ≥3.5；数字、人名、专业词不能念错；长句吞字 ≤1 处。
- 不达标先重录样本（10–20 s、安静环境、正常语速），别靠调参数硬顶；客户书面确认 3 句试听后，才允许批量合成。

**② 失败降级到预设音色**

- 用三种方式制造失败：删掉 `DASHSCOPE_API_KEY`、把 `target_model` 写错、传一个已删除的 `cl_` id。
- 断言：`synthesize` 抛 `VoiceError`（带 `status`），UI 按 §1 的重试逻辑**只降级一次**到 `DEFAULT_VOICE_ID`，提示「已降级为预设音色」，成片仍能导出；不出现 `Failed to fetch` 这类原始报错，也不静默混用音色。

**③ 删除样本后不可再用**

- `deleteClone(id)` 后：`listVoices()` 不再出现；用旧 id 调 `/api/tts` 返回 `404 CLONE_NOT_FOUND` 且不产生上游费用。
- 百炼侧 `list_voice` 查不到该 `voice_id`；样本直链 403/404；本地与 CDN 缓存清掉。
- 重复 `DELETE` 返回 404/204，前端不报错；换设备/清 cookie 后也读不到（归属校验生效）。

---

**施工顺序**：先上 `GET`（只回空列表）跑通前端 → 再上 `POST` 打通 `create_voice + 轮询` → 最后接合成与删除。每一步都可以独立上线，前端不会因为 501 白屏。
